# Типы аккаунтов

Тип аккаунта определяет, к какому внешнему сервису он подключается и какие данные нужно указать.

MarketAut поддерживает следующие типы аккаунтов:

- [Wildberries](#wildberries) — подключение по API-токену Wildberries.

## Wildberries {#wildberries}

Позволяет работать с данными магазина через API Wildberries:

- карточки товаров;
- цены и скидки;
- заказы, поставки и пропуска FBS;
- вопросы, отзывы, чат с покупателями и возвраты;
- финансовые и аналитические отчёты;
- документы.

Полный список — в разделе [Инструменты](../4-platform/05-tools.md).

### Получение токена

Для создания аккаунта нужен API-токен Wildberries. Создать его может только владелец личного кабинета.

Как получить токен и какие категории доступа выбрать — в разделе [Получение API-токена](../3-start/03-api-token.md).
