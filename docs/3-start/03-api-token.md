# Получение API-токена Wildberries

Для подключения аккаунта к MarketAut необходимо получить API-токен Wildberries.

Войдите в личный кабинет продавца Wildberries и откройте раздел **Доступ к API**.


```md
![Раздел «Доступ к API»](img/api-token/01-api-menu.png)
```

Нажмите **Создать токен**, укажите название токена и выберите необходимые категории доступа.

```md
![Создание API-токена](img/api-token/02-create-token.png)
```

После создания Wildberries отобразит API-токен. Скопируйте его и сохраните.

!!! warning "Важно"

    API-токен отображается только один раз. Если он был утерян, потребуется создать новый.

```md
![Полученный API-токен](img/api-token/03-copy-token.png)
```

После получения токена вернитесь на **Домашнюю страницу** MarketAut.

Вставьте API-токен в поле **Введите WB API-токен** и нажмите **Сохранить**.

```md
![Добавление API-токена](img/home/add-token.png)
```

После сохранения токена аккаунт будет настроен, и вы сможете запустить диаграмму и получить ссылку для подключения ИИ-агента.
