# Часто задаваемые вопросы


## С какими ИИ-сервисами работает MarketAut?


**MarketAut** работает с ИИ-агентами, поддерживающими протокол [MCP](https://modelcontextprotocol.io/docs/getting-started/intro).

MCP — это протокол, который позволяет языковой модели подключаться к внешним инструментам и данным. Благодаря этому модель может не только отвечать на вопросы, но и выполнять действия через инструменты MarketAut.

На текущий момент подключение к MarketAut доступно для **ChatGPT**, **Claude**, **Gemini**, **Grok** и **QwenWork**. Инструкции размещены в разделе [Работа с ИИ](/5-ai/00-intro/).

| Сервис   | Тип                                       | Поставщик     | Официальный сайт                               |     |
| -------- | ----------------------------------------- | ------------- | ---------------------------------------------- | --- |
| ChatGPT  | ИИ-ассистент                              | OpenAI        | [chatgpt.com](https://chatgpt.com)             |     |
| Claude   | ИИ-ассистент                              | Anthropic     | [claude.ai](https://claude.ai)                 |     |
| Gemini   | ИИ-ассистент                              | Google        | [gemini.google.com](https://gemini.google.com) |     |
| Grok     | ИИ-ассистент                              | xAI           | [grok.com](https://grok.com)                   |     |
| QwenWork | Рабочая ИИ-платформа на базе моделей Qwen | Alibaba Cloud | [qwenwork.ai](https://qwenwork.ai/)            |     |

 После подключения языковая модель сможет использовать инструменты MarketAut, доступные пользователю согласно его правам: получать данные, работать с подключёнными сервисами и выполнять действия через инструменты платформы.
## Нужен ли мне аккаунт у поставщика ИИ?

Да, нужен. **MarketAut не предоставляет собственные языковые модели** — платформа подключает ваш магазин **Wildberries** к выбранному ИИ-сервису через протокол MCP.

Пользователь самостоятельно регистрируется у поставщика ИИ, при необходимости оплачивает подписку и получает доступ к выбранному сервису.
