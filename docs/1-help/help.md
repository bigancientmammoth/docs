# Часто задаваемые вопросы


## С какими ИИ-сервисами работает MarketAut?


**MarketAut** работает с ИИ-агентами, поддерживающими протокол [MCP](https://modelcontextprotocol.io/docs/getting-started/intro).

MCP — это протокол, который позволяет языковой модели подключаться к внешним инструментам и данным. Благодаря этому модель может не только отвечать на вопросы, но и выполнять действия через инструменты MarketAut.

На текущий момент подключение к MarketAut доступно для **ChatGPT**, **Claude**,**Grok** и **QwenWork**. Инструкции размещены в разделе [Работа с ИИ](/5-ai/00-intro/).

| Модель   | Тип                                       | Поставщик     | Официальный сайт                    |
| -------- | ----------------------------------------- | ------------- | ----------------------------------- |
| ChatGPT  | ИИ-ассистент                              | OpenAI        | [chatgpt.com](http://chatgpt.com)   |
| Claude   | ИИ-ассистент                              | Anthropic     | [claude.ai](http://claude.ai)       |
| Grok     | ИИ-ассистент                              | xAI           | [grok.com](http://grok.com)         |
| QwenWork | Рабочая ИИ-платформа на базе моделей Qwen | Alibaba Cloud | [qwenwork.ai](https://qwenwork.ai/) |

 После подключения языковая модель сможет использовать инструменты MarketAut, доступные пользователю согласно его правам: получать данные, работать с подключенными сервисами и выполнять действия через инструменты платформы.
## Нужен ли мне аккаунт у поставщика ИИ?

Да, нужен. **MarketAut не предоставляет собственные языковые модели**. Платформа позволяет подключить аккаунт выбранного **поставщика ИИ** например **Claude** или **ChatGPT**. Его можно подключить к магазину **Wildberries** через протокол MCP.

Пользователь самостоятельно регистрируется у поставщика ИИ, оплачивает подписку и получает доступ к выбранному сервису.
